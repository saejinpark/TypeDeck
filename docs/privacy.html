TypeDeck

개인정보 처리방침

시행일: 2026년 11월 11일

TypeDeck(맥 앱과 웹 앱)은 개인정보를 수집하지 않습니다. 회원 가입, 로그인, 광고, 분석 도구, 추적이 없습니다.

기기에만 저장되는 정보

  • 직접 만든 카테고리, 덱, 카드, 메모와 학습 기록(카드별로 외운 정도)은 사용하는 기기 안에만 저장됩니다. 맥 앱은 앱 전용 보관 폴더에, 웹 앱은 브라우저 저장소(localStorage)에 저장합니다.
  • 이 정보는 개발자를 포함해 누구에게도 전송되지 않습니다. 앱을 지우거나 브라우저 데이터를 지우면 함께 사라집니다.

자료로 덱 만들기

  • 텍스트, CSV, TSV 파일은 기기 안에서만 읽습니다.
  • 맥 앱에서 PDF로 덱을 만들 때는 Apple의 기기 내 모델(Apple Intelligence)과 기기 내 문자 인식을 사용합니다. PDF 내용은 기기 밖으로 나가지 않습니다.

웹 앱 호스팅

웹 앱은 GitHub Pages에서 제공되고, 글꼴은 jsDelivr에서 불러옵니다. 페이지를 여는 과정에서 이 서비스들이 일반적인 접속 기록(IP 주소 등)을 남길 수 있으며, 이는 각 서비스의 방침을 따릅니다. TypeDeck은 이 기록에 접근하지 않습니다.
