TypeDeck 지원

TypeDeck은 키를 보고 값을 손으로 쳐서 외우는 카드 연습기입니다. 자격증 용어, 외국어 단어, 시험 범위처럼 외울 것이면 무엇이든 카테고리와 덱으로 정리해 연습합니다.

⚠︎ 틀린 내용을 외우지 않도록 주의하세요.
손으로 반복해 치면서 머리에 새기는 앱이라, 틀린 카드를 외우면 나중에 바로잡기가 훨씬 어렵습니다. 예시 덱은 AI(Claude)가 만들고 검토한 자료이고, 맥 앱에서 PDF로 만든 카드는 Apple Intelligence가 만든 초안입니다. 시험 대비라면 교재, 공식 기출문제, 사전과 대조해 주세요.

자주 묻는 질문

내 카드는 어디에 저장되나요?
사용하는 기기 안에만 저장됩니다. 맥 앱과 웹 앱은 서로 동기화되지 않습니다.

엑셀로 만든 단어장을 넣을 수 있나요?
+ 메뉴의 '자료로 덱 만들기'에서 CSV, TSV, 텍스트 파일을 고르면 됩니다. 열은 키, 값, 메모 순서입니다. 한국어 엑셀의 기본 CSV도 읽습니다.

뜻이 여러 개인 카드는 어떻게 치나요?
값을 쉼표로 나눠 두면 모든 뜻을 순서대로 칩니다. 뜻 하나를 다 치면 쉼표를 직접 치고, 뒤의 띄어쓰기는 저절로 채워집니다.

PDF로 덱을 만들려면?
macOS 26 이상, Apple Intelligence를 켠 Mac의 맥 앱에서 됩니다. 만든 카드는 바로 저장되지 않고 초안으로 열리니, 원문과 대조한 뒤 저장하세요.
