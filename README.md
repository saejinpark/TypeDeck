# TypeDeck

키와 값을 **손으로 쳐서** 외우는 카드 연습기입니다. 맥 앱과 웹 앱이 같은 덱과 같은 규칙으로 동작합니다.

자격증 용어, 외국어 단어, 시험 범위처럼 외울 것이면 무엇이든 씁니다. 공부할 주제마다 **카테고리**를 만들고, 그 안에 외울 것을 **덱**으로 정리합니다.

- 웹: `docs/` 폴더 (GitHub Pages로 배포할 예정이며, 아직 배포하지 않았습니다)
- 맥: `TypeDeck.xcodeproj` (macOS 15 이상)

## 카테고리와 덱

- **새로 만들기**: 사이드바 맨 위 `+` 메뉴에 '새 덱', '새 카테고리', '자료로 덱 만들기'가 있습니다. 맥은 ⌘N / ⇧⌘N / ⇧⌘O 단축키도 있습니다. 덱이 없는 빈 카테고리도 남아 있습니다.
- **카테고리에 덱 추가**: 카테고리 줄에 마우스를 올리면 나오는 `+`, 또는 빈 카테고리의 '덱 만들기'를 누르면 그 카테고리로 정해진 새 덱이 열립니다. 편집 창에서 카테고리를 바꿔 다른 곳으로 옮길 수도 있습니다.
- **이름 바꾸기**: 웹은 카테고리 줄의 연필 버튼이나 더블클릭, 맥은 오른쪽 클릭 메뉴에서 바꿉니다. 이미 있는 이름으로 바꾸면 두 카테고리를 합칩니다.
- **접기 / 펼치기**: 카테고리 줄을 누르면 접히고 펼쳐집니다. 덱을 고르면 그 카테고리는 저절로 펼쳐집니다.
- **번호 격자**: 이름이 '같은 앞부분 + 짧은 끝 단어(4글자 이하)'인 덱이 2개 이상이면(`회차 01`, `회차 02` … 또는 `한국사1회`, `한국사2회` …) 앞부분을 한 번만 적고 그 아래에 번호를 격자로 보여 줍니다. 번호는 숫자 순서로 정렬되고, 한 카테고리 안에 묶음이 여러 개 있어도(`회차 …`, `테스트 …`) 각각 따로 묶입니다. 이름이 제각각인 덱은 줄로 보입니다. 번호에 마우스를 올리면 전체 이름과 카드 수가 나오고, 맥에서는 오른쪽 클릭으로 편집·삭제할 수 있습니다.
- **지우기**: 덱이나 카테고리 줄의 휴지통 버튼(맥은 오른쪽 클릭 메뉴와 Delete 키도)으로 지웁니다. 카테고리를 지우면 그 안의 덱도 모두 지워지며, 지울 때마다 한 번 확인합니다.
- 카테고리를 비워 둔 덱은 '미분류'에 모입니다.

## 자료로 덱 만들기

- **텍스트·CSV·TSV 파일**: 사이드바 `+` 메뉴의 **자료로 덱 만들기**(맥은 ⇧⌘O)에서 고릅니다. 웹은 덱 편집 창의 '파일에서 불러오기'로 이미 있는 덱에 더할 수도 있습니다. 텍스트는 한 줄에 `키 = 값`(또는 탭, `:`), CSV·TSV는 키, 값, 메모 순서의 열입니다. 따옴표로 감싼 `"지원하다, 신청하다"`는 뜻 두 개로 들어가고, 따옴표 안에서는 줄을 바꿔도 됩니다.
- **PDF (맥, Apple Intelligence)**: 같은 버튼으로 PDF를 고르면 기기 안의 모델이 내용을 읽고 카드를 만듭니다. 아래 'PDF로 덱 만들기'를 보세요.
- 카테고리 줄의 오른쪽 클릭 메뉴(맥)에서 고르면 만든 덱이 그 카테고리에 들어갑니다. 결과는 바로 저장되지 않고 편집기에 초안으로 열립니다.

## 예시 덱

앱을 바로 써 볼 수 있도록 예시 덱이 들어 있습니다. 처음 실행할 때 환영 창에서 넣을지 고르고, 필요 없으면 빈 상태로 시작합니다. 이 화면에서만 넣을 수 있고, 지운 예시 덱은 앱을 업데이트해도 다시 생기지 않습니다. 이미 쓰던 사람에게는 새로 추가된 예시 덱만 한 번 들어갑니다.

### 영어 문장 (문법)

문법이 여러 개 녹아 있는 영어 문장 60개가 주제별 6개 덱(시제와 완료, 조동사와 가정법, 관계사, 부정사·동명사·분사, 비교·강조·도치, 수동태·명사절·수 일치)으로 들어 있습니다. 카드의 키는 한국어 번역, 값은 영어 문장이라서 번역을 보고 영어 문장을 칩니다. 문장마다 핵심 문법, 번호를 붙인 자세한 설명, 외울 틀을 카드 메모로 달아 두었습니다. 다른 예시 덱과 똑같은 평범한 덱이라 필요 없으면 지우면 됩니다.

### 토익 단어장

토익 영단어와 숙어 3,720개가 50개 안팎의 Day 덱으로 들어 있습니다.

| 카테고리 | 카드 | 덱 |
| --- | --- | --- |
| 토익 기초 (600+) | 1,393 | 28 |
| 토익 중급 (800+) | 934 | 19 |
| 토익 고급 (900+) | 508 | 11 |
| 토익 숙어 (구동사, be + 형용사 + 전치사, 동사 + 명사 짝, 전치사구, 업무 표현) | 885 | 19 |

## 어떻게 쓰나

카드에 문제가 나오면 답을 칩니다. 마지막 글자를 치는 순간 Enter 없이 다음 카드로 넘어가고, 입력 포커스는 계속 그대로라서 손을 멈출 필요가 없습니다.

| 키 | 동작 |
| --- | --- |
| 그냥 입력 | 정답과 같아지는 순간 다음 카드 |
| Enter | 정답 보기 (틀린 것으로 기록) |
| Tab | 건너뛰기 (몇 장 뒤에 다시 나옴) |
| Esc | 입력 지우기 |
| 라운드 끝에서 Enter / Tab | 다시 하기 / 틀린 카드만 |

- **따라치기**는 정답이 흐리게 깔려 있고 그 위를 덮어 씁니다. 틀린 글자는 빨갛게 표시됩니다.
- **외워치기**는 정답을 가리고 기억으로 칩니다.
- 값에 뜻이 여러 개면(`줄, 노선, 제품군`) 모든 뜻을 순서대로 칩니다. 뜻 하나를 다 치면 `, `가 저절로 채워지고 다음 뜻으로 넘어가므로 쉼표는 치지 않아도 됩니다(쳐도 됩니다). 마침표·물음표·느낌표로 끝나는 문장과 `1,000`처럼 숫자 사이 쉼표는 나누지 않습니다.
- **뒤집기**는 키와 값을 바꿉니다. 단어 덱이라면 뜻을 보고 영단어를, 용어 덱이라면 설명을 보고 용어를 칩니다.
- **메모**: 모든 카드에 메모(뜻풀이, 예문, 외우는 요령, 문법 설명 등)를 달 수 있고, 카드 아래에 나옵니다. 따라치기에서는 지금 카드의 메모를, 외워치기에서는 방금 다 친 카드의 메모를 보여 줘서 읽느라 타이핑이 끊기지 않습니다. 메모가 없는 카드는 '＋ 메모 쓰기'만 보이고, 연습하다가 바로 쓰거나 '고치기'로 고칠 수 있습니다(⌘Enter 저장, Esc 취소). 위쪽 '메모' 버튼으로 숨길 수 있습니다.
- 한 번이라도 틀리거나 정답을 본 카드는 4장 뒤에 다시 나옵니다. 정확도는 카드마다 첫 시도만 셉니다.
- 타/분은 카드를 치는 동안의 키 입력 수로 잽니다.

## PDF로 덱 만들기 (맥, Apple Intelligence)

사이드바 `+` 메뉴의 **자료로 덱 만들기** 또는 파일 메뉴(⇧⌘O)에서 PDF를 고르면, 기기 안의 Apple Intelligence 모델이 내용을 읽고 카드를 만듭니다. 결과는 바로 저장되지 않고 편집기에 초안으로 열리니, 확인하고 고친 뒤 저장하면 됩니다.

- 글자가 있는 PDF는 그대로 읽고, 스캔한 페이지는 Vision 문자 인식(한국어·영어)으로 읽습니다.
- "word - 뜻", "용어: 정의", 문답처럼 짝이 있는 내용을 우선 카드로 만들고, 없으면 핵심 용어와 짧은 정의를 만듭니다. 원문 언어를 그대로 씁니다.
- 긴 PDF는 구간으로 나눠 처리합니다. 처리하지 못한 구간이 있으면 알려 줍니다.
- macOS 26 이상, Apple Intelligence를 켠 Mac에서 동작합니다. 쓸 수 없는 Mac에서는 이유를 알려 주고, "키 = 값"처럼 구분자가 있는 줄만 카드로 만듭니다.
- 웹 앱에는 이 기능이 없습니다. 웹에서는 텍스트·CSV 파일을 쓰세요.

## 덱 만들기

덱 편집은 키와 값 칸이 나란히 있는 표입니다.

| 키 | 동작 |
| --- | --- |
| Enter | 이름 칸에서 새 카드 칸으로, 키 칸에서 값 칸으로, 값 칸에서 다음 카드로 (한글을 치다가 바로 눌러도 한 번이면 됩니다) |
| ↑ ↓ | 위아래 카드의 같은 칸으로 |
| 빈 칸에서 Backspace | 값 칸이면 키 칸으로, 빈 카드면 지우고 위 카드로 |
| ⌘Enter (맥은 ⌘S도) | 저장 |

- 맨 아래 `+` 줄에 쓰기 시작하면 새 카드가 됩니다.
- 키 칸과 값 칸 사이의 세로줄을 끌면 두 칸의 너비가 바뀝니다. 두 번 클릭하면 처음 비율로 돌아가고, 고른 비율은 기억합니다.
- 여러 줄을 붙여 넣으면 한 줄이 카드 한 장이 됩니다. 탭, ` = `, ` : `, `=`, `:` 순서로 키와 값을 나눕니다. 스프레드시트 두 열을 복사해 그대로 붙여 넣어도 됩니다.
- **메모**: 줄 끝의 메모 버튼을 누르면 카드 아래에 메모 칸이 열립니다. 메모가 있는 카드는 버튼이 주황색입니다. 텍스트로는 카드 줄 바로 아래에 `>`로 시작하는 줄로 씁니다.

```
나는 그를 안다. = I know him.
> know는 상태동사라 진행형으로 쓰지 않는다.
> I am knowing him. (X)
```
- 값에 뜻을 여러 개 넣으려면 쉼표로 나눕니다: `apply = 지원하다, 신청하다`.
- 키나 값이 빈 카드는 빨갛게 표시되고, 저장할 때 한 번 알려 준 뒤 빼고 저장합니다.
- **텍스트** 탭에서는 예전처럼 `키 = 값` 줄로 한꺼번에 고칠 수 있습니다.

## 구조

```
docs/                  웹 앱 (GitHub Pages가 이 폴더를 그대로 배포)
  index.html, app.css    화면
  core.js                카드 파싱, 글자 비교, 세션 규칙, 카테고리 (DOM 없음)
  app.js                 연습 화면, 사이드바, 메모, 첫 실행 환영 창
  editor.js              덱 편집기 (키·값 표, 메모, 파일 불러오기)
  keys.js                한글 입력 중에 누른 Enter도 한 번에 처리
  decks.json             첫 실행 때 고르는 예시 덱(토익 단어, 영어 문장). 맥 앱도 번들에 넣어 씁니다
TypeDeck/              맥 앱 (SwiftUI + AppKit)
  Core.swift             core.js와 같은 규칙의 Swift 구현
  AppModel.swift         덱·카테고리 저장, 연습 세션, 파일 가져오기
  ContentView.swift      사이드바
  PracticeView.swift     연습 화면과 메모
  DeckEditorView.swift   덱 편집기
  WelcomeView.swift      첫 실행 환영 창
  TypingInputView.swift  IME를 직접 받는 입력 뷰
  PDFDeckImporter.swift  PDF 읽기, 문자 인식, Apple Intelligence 카드 생성
  Palette.swift          색과 작은 공용 뷰
tests/                 웹 코어 테스트 (node --test)
TypeDeckTests/         맥 테스트 (Swift Testing)
```

### 딜레이 없이 넘어가는 방법

- **맥**: 텍스트 필드 대신 `NSTextInputClient`를 직접 구현한 뷰 하나가 계속 포커스를 갖습니다. 정답이 완성되면 버퍼만 비우고, 한글처럼 조합 중인 글자는 입력기에 버리라고 알려서 다음 카드로 새지 않게 합니다.
- **웹**: 보이지 않는 입력칸 하나가 계속 포커스를 갖습니다. macOS의 Chrome 계열 브라우저는 한글 조합 중에 값이나 포커스를 바꾸면 글자가 되살아나고 첫 백스페이스가 먹히지 않으므로, 조합 중에는 입력칸을 절대 건드리지 않고 현재 카드가 시작하는 위치만 기억합니다. 이전 정답의 마지막 글자에 다음 자음이 받침으로 붙는 경우(다+ㄱ→닥)도 새 카드에는 ㄱ으로 보입니다. 쌓인 글자는 조합이 없는 순간에 정리합니다.
- 정답보다 길게 한꺼번에 들어온 입력(붙여넣기 등)은 넘친 만큼 다음 카드로 이어집니다.
