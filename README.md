# TypeDeck

키와 값을 **손으로 쳐서** 외우는 카드 연습기입니다. 맥 앱과 웹 앱이 같은 덱과 같은 규칙으로 동작합니다.

- 웹: https://saejinpark.github.io/TypeDeck/
- 맥: `TypeDeck.xcodeproj` (macOS 15 이상)

## 어떻게 쓰나

카드에 키가 나오면 값을 칩니다. 마지막 글자를 치는 순간 Enter 없이 다음 카드로 넘어가고, 입력 포커스는 계속 그대로라서 손을 멈출 필요가 없습니다.

| 키 | 동작 |
| --- | --- |
| 그냥 입력 | 정답과 같아지는 순간 다음 카드 |
| Enter | 정답 보기 (틀린 것으로 기록) |
| Tab | 건너뛰기 (몇 장 뒤에 다시 나옴) |
| Esc | 입력 지우기 |
| 라운드 끝에서 Enter / Tab | 다시 하기 / 틀린 카드만 |

- **따라치기**는 정답이 흐리게 깔려 있고 그 위를 덮어 씁니다. 틀린 글자는 빨갛게 표시됩니다.
- **외워치기**는 정답을 가리고 기억으로 칩니다.
- **뒤집기**는 값을 보고 키를 치게 바꿉니다.
- 한 번이라도 틀리거나 정답을 본 카드는 4장 뒤에 다시 나옵니다. 정확도는 카드마다 첫 시도만 셉니다.
- 타/분은 카드를 치는 동안의 키 입력 수로 잽니다.

## 덱 만들기

덱 편집에서 한 줄에 카드 하나씩 적습니다.

```
대한민국 = 서울
404 = Not Found
```

탭, ` = `, ` : `, `=`, `:` 순서로 구분자를 찾습니다. 스프레드시트 두 열을 복사해 그대로 붙여 넣어도 됩니다.

## 구조

```
docs/            웹 앱 (GitHub Pages가 이 폴더를 그대로 배포)
  core.js        카드 파싱, 글자 비교, 세션 규칙 (DOM 없음)
  app.js         화면과 입력 처리
  decks.json     기본 덱. 맥 앱도 이 파일을 번들에 넣어 씁니다
TypeDeck/        맥 앱 (SwiftUI + AppKit)
  Core.swift     core.js와 같은 규칙의 Swift 구현
  TypingInputView.swift  IME를 직접 받는 입력 뷰
tests/           웹 코어 테스트 (node --test)
TypeDeckTests/   맥 코어 테스트 (Swift Testing)
```

### 딜레이 없이 넘어가는 방법

- **맥**: 텍스트 필드 대신 `NSTextInputClient`를 직접 구현한 뷰 하나가 계속 포커스를 갖습니다. 정답이 완성되면 버퍼만 비우고, 한글처럼 조합 중인 글자는 입력기에 버리라고 알려서 다음 카드로 새지 않게 합니다.
- **웹**: 보이지 않는 입력칸 두 개를 번갈아 씁니다. 정답이 완성되면 다른 칸으로 포커스를 옮기는데, 이때 브라우저가 조합을 끝내므로 남은 글자가 다음 카드에 들어가지 않습니다.
- 정답보다 길게 한꺼번에 들어온 입력(붙여넣기 등)은 넘친 만큼 다음 카드로 이어집니다.

## 테스트

```bash
node --test tests/core.test.mjs
xcodebuild -project TypeDeck.xcodeproj -scheme TypeDeck test
```

웹을 로컬에서 띄우려면:

```bash
python3 -m http.server 8742 --directory docs
```
